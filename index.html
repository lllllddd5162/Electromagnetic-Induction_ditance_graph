문제 1 <보기> 확인

ㄱ. t일 때와 6t일 때 검류계에 흐르는 전류의 방향은 서로 반대이다.
O — t일 때는 간격이 커지고(멀어짐), 6t일 때는 간격이 작아진다(다가옴). 자기장 변화가 반대이므로 전류 방향도 반대이다.
ㄴ. 3t일 때 검류계에 전류가 흐르지 않는다.
O — 2t~4t에서는 간격이 일정하다. 자석이 멈춰 있어 자기장 변화가 없으므로 전류가 흐르지 않는다.
ㄷ. 6t일 때 검류계에 흐르는 전류의 세기는 t일 때보다 크다.
X — 0~2t 구간(기울기 3칸/2칸)이 4t~7t 구간(기울기 3칸/3칸)보다 기울기가 크다. 자석이 더 빠르게 움직이는 t일 때 전류가 더 세다.
정답 ③ ㄱ, ㄴ

문제 2 확인

1. 3초일 때와 9초일 때 전류의 방향은 같을까?
반대. 3초에는 d가 커지고(자석이 멀어짐), 9초에는 d가 작아진다(자석이 다가옴).
2. 7초일 때 검류계 바늘은?
0을 가리킨다. 6~8초에는 d가 일정해 자기장 변화가 없다.
3. 전류의 세기는 3초와 9초 중 언제 더 클까?
9초. 8~10초 구간의 기울기가 0~6초 구간보다 크다. 같은 간격 변화를 더 짧은 시간에 하므로 자석이 더 빠르다.
